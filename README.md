    NP 问题（多项式时间可验证问题）：这就像你找到了一个宝藏箱，装有一个巨大的数字锁，但你没有解锁工具。你可以尝试不同的密码组合，但你无法确定哪一个是正确的。然而，一旦你猜到了一个密码，你可以轻松地用它来验证是否正确。如果是正确的，你就找到了宝藏。
